# AlphaGate 架构设计

## 总体架构

AlphaGate 是一个**语义门控金融推理与资产配置平台**，围绕财跃星辰 x 上海交大开源
金融推理大模型 Alpha-R1（8B）的核心技术「语义门控」与「两阶段强化学习」工程化。

## 核心概念：语义门控（Semantic Gating）

Alpha-R1 的核心思想：每次决策前，把「当前市场状态描述」与每条候选配置思路附带的
「经济逻辑说明书」逐条做**语义匹配**，只放行逻辑与当下环境吻合的思路，其余一律拦截。

本平台将该机制落地为可复现的工程实现：

1. **市场状态建模**：行情指标（动量/波动/回撤/夏普）+ 财经新闻 → `MarketRegime`
2. **语义匹配**：`SemanticGate` 用可插拔嵌入后端（hash/bow/tfidf）计算状态文本与
   思路说明书的余弦相似度
3. **门控决策**：相似度 >= 阈值则放行，按匹配分 softmax 归一化为权重
4. **可解释输出**：每个放行/拦截都附「为什么」的理由

## 两阶段强化学习

- **Stage 1 偏好对齐**：把「市场状态 → 应放行思路」规则蒸馏为可评估决策器
- **Stage 2 GRPO**：组内相对奖励驱动的阈值优化，最大化门控正确性 + 组合收益

## 模块清单

| 模块 | 职责 |
|---|---|
| `core` | 类型/异常/配置/注册表/上下文/市场状态/思路/门控决策 |
| `gate` | 语义门控引擎、嵌入后端、状态构建、解释器、提示词 |
| `strategies` | 12 条配置思路 + 经济逻辑说明书 + YAML 策略卡 |
| `data` | 行情接入（mock/csv/akshare）、因子、指标、缓存、新闻 |
| `rl` | 两阶段强化学习训练 |
| `serving` | FastAPI REST + OpenAI 兼容端点 |
| `backtest` | 回测引擎、组合构建、绩效、归因、风控 |
| `agents` | 研究员/配置官/风控官/报告官 多智能体 |
| `catalog` | 模型卡 + 策略卡（YAML） |
| `cli` | 命令行入口 |

## 设计取舍

- **不训练模型**：在开源金融推理模型之上做工程化，`model.backend=mock` 离线可跑
- **可插拔**：数据源/嵌入后端/模型后端均注册表驱动，填配置即切换
- **可解释**：每个决策都有 reason 与 rationale，输出「人话」
- **可复现**：mock 数据源确定性伪随机，seed 固定可复现
