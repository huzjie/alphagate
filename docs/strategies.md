# 配置思路库（18 条）

每条配置思路都附「经济逻辑说明书」（rationale），语义门控据此判断当下环境该启用哪条。

## 核心类（12 条）

| 思路 | 适配环境 | 说明 |
|---|---|---|
| 价值 | 震荡/熊市 | 低估值均值回归，安全边际 |
| 动量 | 牛市 | 顺势加仓强势板块 |
| 质量 | 牛市/震荡 | 盈利质量稳定穿越周期 |
| 低波 | 高波动/避险 | 下行保护更好 |
| 红利 | 熊市/避险 | 高股息稳定现金流 |
| 成长 | 牛市/流动性宽松 | 高成长估值溢价 |
| 反转 | 熊市/高波动 | 超跌均值回归 |
| 趋势跟踪 | 牛/熊 | 均线通道右侧跟随 |
| 防御 | 高波动/衰退 | 降仓增配债券 |
| 流动性 | 流动性宽松 | 资金面主导 |
| 小盘 | 流动性宽松/牛市 | 小市值弹性 |
| 风险平价 | 震荡/高波动 | 跨资产风险预算 |

## 扩展类（6 条）

| 思路 | 适配环境 | 说明 |
|---|---|---|
| 行业轮动 | 牛市/震荡 | 景气行业切换 |
| 宏观 | 震荡/熊市 | 自上而下大类资产 |
| 事件驱动 | 牛市/宽松 | 并购/财报/政策催化 |
| 技术面 | 牛/熊/高波动 | 量价择时 |
| 资金流 | 牛市/宽松 | 跟随北向主力 |
| 情绪面 | 高波动/熊市 | 情绪逆向 |
