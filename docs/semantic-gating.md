# 语义门控原理与实现

## 为什么需要语义门控

传统资产配置的问题：

1. **通用大模型不懂经济逻辑**：能读新闻，但不会把新闻与具体配置决策关联
2. **静态配置永远慢半拍**：去年管用的思路，今年市场风格切换就失灵

Alpha-R1 的解法：**语义门控** —— 像医生对症下药，而不是闭眼抓药。

## 三步流程

1. **构建市场状态描述**：`RegimeBuilder.build(indicators, news)` → `MarketRegime`
2. **语义匹配**：`SemanticGate.decide()` 计算状态文本与每条思路说明书的余弦相似度
3. **门控 + 权重**：相似度 >= 阈值放行，softmax 归一化为权重

## 示例

输入市场状态「市场上行、动量强劲」，候选思路：
- 动量（趋势延续时顺势加仓）→ 高匹配 → 放行
- 防御（高波动降仓）→ 低匹配 → 拦截
- 价值（低估值均值回归）→ 中匹配 → 视阈值

## 可插拔嵌入后端

| 后端 | 特点 |
|---|---|
| `hash` | 特征哈希，无模型、确定性、离线 |
| `bow` | 词袋，需 fit 词表 |
| `tfidf` | TF-IDF，需 fit 语料 |

切换：`SemanticGate(embedder="tfidf")` 或 `config.yaml: gate.embedder`。

## 阈值调优

阈值越低放行越多（组合越分散），越高越聚焦。建议 0.15~0.35 之间。
用 `alphagate train` 通过 GRPO 自动优化阈值。
